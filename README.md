# Среда для создания карт

## Эксплуатирование
Чтобы закрасить пространство между клетками - зажмите колёсико мыши и проведите там, где нужно сделать линию между клеток
Чтобы закрасить клетку серым/чёрным зажмите ЛКМ и проведите по клеткам, которые хотите закрасить
Если провести с ЛКМ по белым клеткам - они станут серыми; Если провести по серым - они станут чёрными; Если провести по чёрным - станут белыми
ПКМ делает клетку только белой
Нажатие Spase очищает всё поле!
Можно помечать клетки оранжевой звёздочкой, если провести по ним с ЛКМ+B
Можно красить клетки в разные цвета, если провести по ним с ЛКМ+C
Чтобы выбрать цвет зажмите C и нажмите на цифру от 1 до 9; В конце будет список цветов
Если вы хотите сохранить свою "карту", нажмите S
Если вы хотите загрузить сохранённую "карту", нажмите L
Цвета:
1 - зелёный
2 - синий
3 - красный
4 - жёлтый
5 - фиолетовый
6 - оранжевый
7 - коричневый
8 - розовый
9 - бирюзовый
